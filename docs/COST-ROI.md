# 비용·ROI 시나리오와 2분 시연

Figma의 기존 비용 그래프 자리에서 비용 비교·ROI 입력 화면으로 범위를 확장했습니다.

- [비용 비교](https://www.figma.com/design/M6iBTw20Bc1xbjXsy1m0xi?node-id=224-644)
- [ROI 계산](https://www.figma.com/design/M6iBTw20Bc1xbjXsy1m0xi?node-id=224-717)
- 팀원 페이지에도 동일한 개인 입력 시나리오 디자인을 배치했습니다.

일반 서비스의 `비용 · ROI 시나리오` 메뉴(`/teams/:teamId/:workspace/cost-roi`)와 `/demo`의 `6. 비용 · ROI`에서 동일한 시나리오 계산기를 사용합니다. 일반 서비스의 시나리오 입력은 빈 상태로 시작하고 `/demo`는 합성 가정을 제공합니다. 시나리오 계산은 입력한 가정과 단가를 사용합니다.

## 실제 토큰 비교

로그인한 팀원·팀장은 같은 메뉴의 **실제 토큰 비교**에서 공통 업무와 두 프롬프트를 입력합니다. 실행 전에 모델과 OpenAI 전송 안내를 확인할 수 있습니다. 브라우저는 TOKI 백엔드의 `/api/v1/teams/{teamId}/prompt-comparison`만 호출하며, OpenAI 프로젝트 키는 백엔드에 설정합니다. 로컬 실행 시 `API_PROXY_TARGET`을 해당 백엔드 주소로 지정합니다.

화면은 OpenAI가 반환한 입력·출력·총 토큰, 캐시 입력 토큰, 두 응답을 함께 표시합니다. 두 응답이 같은 모델에서 모두 완료됐을 때만 증감률 `(기존 총 토큰 − 개선 총 토큰) ÷ 기존 총 토큰`을 계산합니다. 응답이 잘리거나 실패하면 실행별 결과와 확인된 사용량을 표시합니다. 두 결과가 같은 업무 요건을 충족하는지는 응답 본문에서 확인합니다.

**OpenAI 호출 식별 정보**에 각 호출의 요청·응답 ID가 표시됩니다. 대시보드에서 프로젝트·모델·UTC 시간대별 사용량을 대조할 수 있습니다. [OpenAI API 사용량 안내](https://help.openai.com/en/articles/10478918-reviewing-api-usage-and-costs)

## 계산식

같은 기간·업무 수·품질과 동일한 입력/출력 단가를 가정합니다. 토큰은 업무 1건에서 발생한 모든 요청을 합산한 값으로 입력합니다. 반복 전송한 맥락도 포함해야 합니다.

- AI 비용(KRW) = (입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가) / 1,000,000 × 환율 × 업무 수
- 지출 감소 추정 = 개선 전 AI 비용 − 개선 후 AI 비용
- 절감 시간 = (개선 전 검토·재작업 분 − 개선 후 분) × 업무 수 / 60
- 시간 절감 가치 = 절감 시간 × 시간당 인건비
- 도입 총비용 = 초기 설정 + 교육 + 서비스 이용료 + 업로드·확인·오판 대응비
- AI 지출만 반영한 ROI(%) = (지출 감소 추정 − 도입 총비용) / 도입 총비용 × 100
- 시간 가치 포함 ROI(%) = (지출 감소 추정 + 시간 절감 가치 − 도입 총비용) / 도입 총비용 × 100

입력 누락·유효하지 않은 날짜·역전된 기간·음수 입력·무한대·범위 초과·미확인 가정은 계산 대기로 표시합니다. 0 토큰·0 단가는 명시적으로 입력할 수 있으나 업무 수·환율은 양수여야 합니다. 도입 총비용이 0이면 비용 비교는 유지하고 ROI는 계산 불가로 표시합니다. 지출 증가·추가 시간·음수 ROI를 0으로 보정하지 않습니다. 중간 계산은 반올림하지 않고 금액은 표시할 때 원 단위, ROI는 소수 첫째 자리까지 표시합니다.

## 합성 예시

2026-11-01~30, 1,000건, 개선 전 입력/출력 12,000/4,000토큰, 개선 후 8,000/2,500토큰, 입력/출력 단가 USD 2.5/10(100만 토큰당), 환율 1,400을 가정합니다. 이는 현재 모델 가격이나 실제 환율에 대한 주장이 아닙니다.

개선 전 98,000원, 개선 후 63,000원, 지출 감소 추정 35,000원입니다. 업무당 6분→3분, 시간당 30,000원을 가정하면 50시간·1,500,000원의 시간 가치입니다. 도입비 500,000원으로 AI 지출 ROI −93%, 시간 가치 포함 ROI 207%입니다. 개선 후 시간을 4분으로 바꾸면 후자는 107%로 변합니다.

실제 지출 감소와 시간 가치는 다른 효과입니다. 품질 유지·교육의 인과효과·공급자 청구액·캐시·추론·세금·정액 구독 비용을 재현하지 않습니다. 가정 출처와 계산식은 화면에서 확인합니다.

## 2분 녹화

로컬 FE 서버를 5175에서 실행한 뒤 FE 디렉터리에서 `node scripts/record-demo.mjs`를 실행합니다. `DEMO_VIDEO_URL`로 다른 데모 URL을 지정할 수도 있습니다. 새 비용·ROI 코드가 없는 배포본에서는 해당 단계가 실패하므로 먼저 변경 반영 여부를 확인해야 합니다.

출력은 프로젝트 `output/presentation-demo/`에 생성됩니다. 자막이 포함된 WebM, SRT, 타임코드별 내레이션 대본, 녹화 검증 JSON이 저장됩니다. 음성은 포함하지 않습니다. 실제 브라우저를 조작해 녹화하며 DOM 오류와 예상하지 않은 `/api/` 요청이 있으면 실패합니다.

녹화 후 `node scripts/export-demo.mjs`를 실행하면 같은 폴더에 `TOKI_2분_시연.mp4`가 생성됩니다. FFmpeg를 PATH에 추가하거나 실행 파일 경로를 `FFMPEG_PATH`에 지정합니다. 오프닝과 엔딩에는 TOKI 캐릭터와 로고를 크게 표시하고, 데모 화면에서는 자막 위 오른쪽 아래에 캐릭터를 작게 표시합니다. 완성본은 1600×900, 30fps, 2분입니다.

| 구간      | 화면                               |
| --------- | ---------------------------------- |
| 0~18초    | 서비스 소개·샘플 3건 선택          |
| 18~35초   | 분석 진행·피드백 유형              |
| 35~56초   | 개선 전후·근거 대화·도움됨         |
| 56~74초   | 과거 주간 팀 성과·팀장 가이드 지정 |
| 74~91초   | 토큰·가정 단가·비용 비교           |
| 91~113초  | 두 종류 ROI·업무당 시간 변경       |
| 113~120초 | 전체 흐름 정리                     |

팀 성과 화면에는 별도로 준비한 과거 주간 합성 집계를 표시합니다. 시연에서 선택한 대화 3건과 ROI 입력값은 각각 독립된 예시입니다. 자막에서도 집계와 가정을 구분합니다.
