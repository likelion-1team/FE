## 시연 흐름

1. 팀 선택 → 업무 준비에서 분석 대상과 조건 확인. 팀장은 설정·팀원 관리, 팀원은 조회.
2. 파일 올리기 → 후보 대화 선택 → 분석 시작. 분석 대상·선택 제한·중복 상태 확인.
3. 분석 확인 → 성공한 피드백 열기. 실패하면 원인 안내를 확인하며 성공으로 대체하지 않음.
4. 피드백 읽기 → 개선 프롬프트·근거 대화 → 실제 업무 결과와 재작업 이유 확인.
5. 나의 성과·팀 성과 확인. 공개·표본 조건 미충족은 0으로 바꾸지 않음.
6. 가이드 활용 → 다음 대화 업로드로 반복. 공유 승인은 별도 미리보기 확인 뒤 진행.

진행 단계 메뉴는 현재 화면을 표시하는 탐색 메뉴입니다. 실제 분석이나 업무가 완료되지 않았는데 ‘완료’로 표시하지 않습니다.
