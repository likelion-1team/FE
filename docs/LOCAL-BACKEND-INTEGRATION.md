# PR #6 통합 및 로컬 백엔드 시연 — 2026-11-26

PR #6을 CI 성공 확인 후 main에 병합했습니다. 작업 브랜치에는 기존 데모 UI 문구 정리와 후속 보완을 함께 유지합니다.

추가 보완:
- 공유 미리보기는 배포 BE의 `redactionStatus=PASSED`만 허용합니다. 실패한 비식별 내용은 승인 화면에 표시하지 않습니다.
- 미리보기 만료 시 승인 버튼을 막고 요청 직전에도 확인합니다. 미리보기를 생성할 때의 공유 버전을 승인 요청에 사용합니다.
- 철회 후 재승인하면 공유 상태·버전을 다시 반영합니다. 업무 결과·재작업 저장 후 지표 캐시도 갱신합니다.
- 팀 성과는 서버 목록 순서와 무관하게 가장 최근 완료 주간을 기본 선택합니다.
- FE 전용 `/demo`의 구현 설명을 줄이고 기본 시연 버튼을 앞세웠습니다.

별도 BE 기능 브랜치의 `demo` 프로필을 실행하면 http://127.0.0.1:5175/login 에서 운영과 분리된 실제 로컬 API를 시연할 수 있습니다. FE 실행 환경은 `API_PROXY_TARGET=http://127.0.0.1:8081`, `VITE_API_BASE_URL=/api/v1`, `VITE_AUTH_TRANSPORT=auto`, `VITE_EMAIL_CHECK_METHOD=GET`입니다. 이 주소의 `/demo`는 FE 목업이므로 백엔드 통합 검증은 일반 로그인으로 진행합니다.

백엔드의 `docs/LOCAL-DEMO.md`에 MySQL 분리·실행·합성 계정·시드 방법을 정리했습니다. 시드가 만든 팀 6명·24개 항목·결과 확인·공유·가이드를 사용합니다. 동일 파일의 5개 행(동일 대화 1개 중복)이 4개 후보·4개 분석 항목만 만들고 총 집계 24건·성공률 75%·오류 재작업률 25%인 것을 API로 검증했습니다.

Chrome에서 로컬 계정 로그인·팀 선택·팀 성과 75%/25%·피드백 상세·업무 결과/재작업 버전 2 저장·공유 미리보기/승인·버전 원문 하이라이트를 확인했습니다. 합성 AI 응답을 사용했으며 운영 데이터나 외부 LLM 품질 검증을 완료했다는 의미는 아닙니다.

검증: lint·타입 검사·빌드, 단위/컴포넌트 42개, 브라우저 시나리오 43개 통과. 기존 40개와 공유 재승인·비식별 실패·만료 차단 신규 3개를 확인했습니다. BE는 MySQL 8.4의 분리된 `toki_test` 스키마에서 402개 테스트·실패 0건을 확인했습니다.
